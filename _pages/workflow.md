<h1>Workflow</h1>

* Extracting existing lexical information (rekeying, OCR, ML, etc.)
* Creative preprocessing and cleaning (openrefine, python, R)
* Analysing metadata and creating a minimal ontology (Google sheets)
* Definition of ontology in triples using standard vocabularies (RDF, Ontolex, OLiA, etc. or a combination thereof)
* Building draft of lemma base from lexical attestations, standardising contributions
* Collaborative effort using GitHub
* Hosting lemma base on static site
